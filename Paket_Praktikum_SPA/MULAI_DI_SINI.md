# Paket Praktikum React SPA

1. Baca Modul_Praktikum_Effect_Custom_Hook_Router.docx.
2. Buka praktikum-spa/README.md untuk instalasi dan struktur file.
3. Pada terminal, masuk ke praktikum-spa lalu jalankan npm ci dan npm run dev.
4. Isi docs/Lembar_Pengujian.md dan docs/Template_Laporan.md.
5. Kerjakan tugas mandiri pada modul setelah implementasi inti dipahami.

Folder node_modules tidak disertakan karena dipasang oleh npm ci.
Semua kode aplikasi dan konfigurasi yang diperlukan sudah tersedia.
